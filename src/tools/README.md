# SocNetV Tools

This directory contains headless utilities used for refactoring safety nets.

## socnetv-cli

`socnetv-cli` loads a dataset headlessly (no GUI) and runs one of nine analysis kernels — distance,
reachability, walks, prominence, io_roundtrip, clustering, connectivity, matrix,
vertex_connectivity — dumping or strictly comparing deterministic JSON golden outputs.

See: [SOCNETV_CLI_REGRESSION_TOOL](../../docs/SOCNETV_CLI_REGRESSION_TOOL.md)
